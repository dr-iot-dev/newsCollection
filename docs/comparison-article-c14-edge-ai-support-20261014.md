# 製造業向けエッジAI支援3構成の基盤統合・運用と実装検討

製造業でエッジ環境を活用する際には、設備データを集める基盤、分散端末の運用、AIを製品へ組み込むための評価など、異なる課題がある。日立情報通信エンジニアリングの統合サービス、Idein・CTCのActcast＋D-Native構成、TEDのTry it! SLM on Edgeを、支援工程と提供段階から整理する。完成製品の同一機能比較ではなく、取り組む課題と支援範囲の違いを読む。

## 比較の考察

日立情報通信エンジニアリングは、製造・プラント向けのエッジAIゲートウェイ インテグレーションサービスを販売開始すると発表した。IoTデータ収集、OTネットワーク、OTセキュリティと将来のAI活用の基盤を統合する位置付けである。一方、IdeinとCTCはActcastとD-Nativeを組み合わせる製造業向け構成の共同開発を発表した。TEDはエッジSLMの評価から製品実装を見据えた検討を支援する体制を整備している。販売開始、共同開発、評価支援という段階の違いを最初に区別したい。 [資料1](https://prtimes.jp/main/html/rd/p/000000047.000069738.html) [資料2](https://prtimes.jp/main/html/rd/p/000000103.000026271.html) [資料3](https://prtimes.jp/main/html/rd/p/000000318.000010609.html)

構成要素では、日立情報通信のサービスはCisco Unified Edgeを採用する仮想基盤に現場の機能を集約すると説明する。Idein・CTCの構成は、Actcastで分散するRaspberry Piなどを管理し、D-Nativeでセンサーデータの蓄積や可視化・分析を支援するものだ。TEDはFoundry Localを使うSLMの基礎理解や調整の考え方を学ぶトレーニングを案内し、検証用ミニPCはオプションで提供する。仮想基盤、端末管理とデータ活用、モデルの評価環境は、それぞれ担当する役割が異なる。 [資料1](https://prtimes.jp/main/html/rd/p/000000047.000069738.html) [資料2](https://prtimes.jp/main/html/rd/p/000000103.000026271.html) [資料3](https://prtimes.jp/main/html/rd/p/000000318.000010609.html)

導入後の運用を扱う範囲にも差がある。日立情報通信は分散していたハードウェアを集約し、仮想基盤上で機能を配置・拡張することで、工程増設や構成変更時の負荷低減を支援するとする。Actcastの管理では端末の設定変更やソフトウェア更新を遠隔で行う構成が説明される。TEDの専任エンジニアは顧客の製品構成や利用場面に応じて実装を検討する伴走支援であり、同じ工場端末の一括管理を提供するとは今回資料から判断できない。継続運用の管理と製品開発の検討支援を分けて比較する必要がある。 [資料1](https://prtimes.jp/main/html/rd/p/000000047.000069738.html) [資料2](https://prtimes.jp/main/html/rd/p/000000103.000026271.html) [資料3](https://prtimes.jp/main/html/rd/p/000000318.000010609.html)

現場データの利用では、日立情報通信は工程やベンダーをまたぐ設備データによる稼働把握・分析と、OTネットワーク設計を説明する。D-Nativeは温度・湿度・寸法・重量・エネルギー消費量などの蓄積、可視化、分析を伴走型で支援する構成とされる。TEDが焦点を置くのは、SLMをどこでどう使うかという製品実装を見据えた評価・検討だ。資料に記載された目的から、3構成が同じ分析結果や改善効果を出すと推定することはできず、生産性や品質の向上は各社の支援目的として読む。 [資料1](https://prtimes.jp/main/html/rd/p/000000047.000069738.html) [資料2](https://prtimes.jp/main/html/rd/p/000000103.000026271.html) [資料3](https://prtimes.jp/main/html/rd/p/000000318.000010609.html)

開発支援では、Idein・CTCは作業効率化や品質検査に向けた独自アプリをRaspberry Pi上で開発する環境を案内し、CTCによる開発支援も可能としている。TEDはFoundry Localでのトレーニングと、製品構成に応じた専任エンジニアの伴走を組み合わせる。日立情報通信は今後、別のエッジAIエンジニアリングサービスとの組み合わせで用途を広げる方針だ。AI向けの基盤拡張性があることと、特定のAIアプリが既に搭載されていることを同じ意味では扱わない。 [資料1](https://prtimes.jp/main/html/rd/p/000000047.000069738.html) [資料2](https://prtimes.jp/main/html/rd/p/000000103.000026271.html) [資料3](https://prtimes.jp/main/html/rd/p/000000318.000010609.html)

将来の拡充では、Idein・CTCは産業用ロボット制御などへエッジ活用を広げる方針を示すが、今回構成の販売開始や導入完了の実績とは区別する。日立情報通信のメニューは個別見積で、他2資料とは料金の範囲をそろえて比較できない。TEDの検証用ミニPCが標準料金に含まれるとも推定しない。データ収集とOT接続の統合、分散デバイスの運用と分析、SLM評価から製品への組み込み検討のうち、どの工程を整えるかを先に定めることが、この3構成を比較する出発点になる。 [資料1](https://prtimes.jp/main/html/rd/p/000000047.000069738.html) [資料2](https://prtimes.jp/main/html/rd/p/000000103.000026271.html) [資料3](https://prtimes.jp/main/html/rd/p/000000318.000010609.html)

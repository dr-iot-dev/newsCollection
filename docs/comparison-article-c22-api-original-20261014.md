# AIアバター面接による一次選考支援の三サービス比較：対話機能と運用特性に注目

企業の採用面接においてAIアバターが応募者と対話し、選考担当者の負担軽減や評価支援を図るサービスが増加している。パソナ提供の「Career Gate」、Preferred Networksの「タレスカAI面接」、JetBの「Our AI面接」は、それぞれ異なる特徴を持ちながら、応募者との面接対話や評価支援を実施する。本稿では各サービスの利用場面、対話内容の深掘り機能、面接後の情報提供および確認体制、受検環境や料金体系について整理し比較する。導入実績や評価精度の優劣を直接示すものではなく、提供情報に基づく機能と運用の違いに着目する。

各提供元の発表資料に基づく機能と運用工程の整理である。Career Gateの提供元はパソナであり、資料1は基盤APIの採用をAVITAが発表したものである。タレスカの受検・評価・録画確認の記載は、沖縄セルラーの2028年卒夏インターンシップ選考という事例の条件を保った整理である。「資料で確認できず」は非対応を意味しない。

同一条件で3サービスを実測した精度や公平性の比較ではない。導入事例の検証結果や問い合わせ件数から、他社より高い精度や採用効果を判断することはできない。仕様・課金方式は発表時点の記載であり、2026年10月14日時点の契約価格確認ではない。

## 比較の考察

まず、パソナが提供する「Career Gate」は、応募者多数の企業に対する一次面接支援を目的とする。AIアバター面接官が採用活動の初期選考の負荷を軽減し、候補者の回答に応じて深掘り質問を重ねる対話が特徴である。面接内容の要約とスコアリングも行い、企業の採用効率化を支援している。なお、AIアバターの表示にはAVITAの「AVITA AVATAR API」が使われているが、API全体の細かな仕様やプライバシー要件はCareer Gateのサービス仕様に直結しない。 [資料1](https://prtimes.jp/main/html/rd/p/000000111.000085375.html)

次に、Preferred Networksの「タレスカAI面接」は、AIアバターとの面接により求職者の適性を多面的に評価する支援ツールである。具体的には潜在能力、コミュニケーション能力、問題解決能力、ビジネス理解力などを想定評価対象としている。沖縄セルラーの2028年卒夏インターンシップ選考での導入事例が示されており、170名が参加した同選考ではAIが4指標で評価し、面接録画は採用担当者が確認した上で最終判断に繋げている。こうした運用は初年度かつ単一企業のケースに限定されており、業界全体での必須工程や効果とは異なる点に留意が必要である。受検は24時間・場所を問わず可能で、多様な応募者に受検機会の公平性を提供したと説明されている。 [資料2](https://prtimes.jp/main/html/rd/p/000000033.000156310.html)

また、JetBが展開する「Our AI面接」は、企業側が用意した質問と評価項目設定に基づき、AIアバターが応募者と対話する仕組みである。回答内容に沿い追加質問を行うほか、面接終了後には動画と文字起こし、加えて分析結果や評価根拠の詳細なレポートを提供する。採用担当者はこれらを都合のよい時間に確認でき、日程調整や面接同席の必要がなく工数削減につながるとされる。最終的な採否判断は人が行う運用形態である。受検は24時間365日可能で、PCやスマートフォン、タブレットから利用でき、アプリのインストールや受検者アカウント登録も不要である。料金は面接数に依らず月額固定で従量課金はないが、具体的な金額は公開されていない。 [資料3](https://prtimes.jp/main/html/rd/p/000000113.000010333.html)

以上三者を利用場面で比較すると、Career Gateが応募者多数の企業における一次面接の深掘り質問やスコアリング支援に特化しているのに対し、タレスカAI面接は求職者の多面的適性評価を目標とし、特定導入事例に基づいた運用例が示されている。Our AI面接は企業ごとの質問設計を活かしつつ、動画とレポートでの評価情報提供に重点が置かれている。どのサービスもAIが面接を実施するが、採否の最終判断には人が関わる点で共通している。 [資料1](https://prtimes.jp/main/html/rd/p/000000111.000085375.html) [資料2](https://prtimes.jp/main/html/rd/p/000000033.000156310.html) [資料3](https://prtimes.jp/main/html/rd/p/000000113.000010333.html)

受検環境では、タレスカAI面接が実証事例として24時間場所を問わずの利用を確認できる一方、Our AI面接は登録やアプリ不要で24時間365日対応可能と説明し、利用の柔軟性を打ち出している。Career Gateの受検条件や時間対応についての詳細は資料に明記がないため判断を保留する。費用面ではOur AI面接のみ具体的な価格体系が示されており、面接数にかかわらず月額固定料金制で従量課金無しであると説明されている。Career GateとタレスカAI面接の料金構造は公式情報に掲載がない。 [資料1](https://prtimes.jp/main/html/rd/p/000000111.000085375.html) [資料2](https://prtimes.jp/main/html/rd/p/000000033.000156310.html) [資料3](https://prtimes.jp/main/html/rd/p/000000113.000010333.html)

これら三つのAIアバター面接サービスは、いずれも応募者との対話から得られる情報を選考担当者に提供し採用業務を効率化することを狙いとしているが、サービスの機能詳細や運用事例、対応時間帯、費用体系には差異がある。導入検討時には、利用シーンや求める評価軸、面接担当者の運用負担軽減ニーズなどを踏まえ、各サービスの公開情報を精査し適合度を判断することが望ましい。導入効果や評価の公平性、選考成功率を断定する比較資料は存在しないため、評価の参考は機能と提供実例の説明にとどめるべきである。 [資料1](https://prtimes.jp/main/html/rd/p/000000111.000085375.html) [資料2](https://prtimes.jp/main/html/rd/p/000000033.000156310.html) [資料3](https://prtimes.jp/main/html/rd/p/000000113.000010333.html)

## 検証状態と利用上の判断

ローカルで使えるモデルが1種類だったため、同じモデルによるA/B初稿の補助点検を各候補で1回試した。C13のみA/Bを入れ替えて執筆元を伏せた。しかし3件とも所定の12項目JSON形式に適合せず、点検結果を合格・不合格の評価には採用していない。再試行は行っていない。これは今回のモデル・テンプレート・サーバー・スキーマ設定を含む処理の観察であり、原因をモデル単独に特定できない。

ローカル編集後は、Codexによる編集・原文照合と15項目の決定的検査を実施した。純粋なローカルモデル出力は「生成直後」のファイルで確認できる。API版にも同様に編集が入っている。編集後の差はモデル能力だけの差とは判断できない。

現時点では、ローカル生成を原文照合を伴う下書き用途に使えることは確認できた。今回の3件だけで、API生成と同じ確認工程を省略できる、自動公開できる、モデル全般の優劣が決まるとは判断しない。

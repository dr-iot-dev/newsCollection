# 外観検査の携帯測定・AI学習・ライン実演の工程差

外観検査を支えるデジタルドットゲージ、StellaDeepVision Studio、メキキバイトの新デモ機を、検査対象、準備、判定後の処理から整理する。塗装面の携帯測定、検査AIの学習基盤、ライン上の検査・排除実演という役割が異なる。発表資料が示す操作と支援範囲を比較し、展示デモや提供元の効果説明を実工場の共通性能へ置き換えない。

## 比較の考察

検査を行う場面は共通していても、扱う対象と構成は異なる。アインソリューションズのデジタルドットゲージは、塗装面に付着したゴミ物の大きさを拡大してAIで判定するハンディ装置である。PhoxterのStellaDeepVision Studioは、良品画像をもとに外観検査のAIを学習させる基盤となる。フツパーが紹介したメキキバイトの新デモ機は、多列の製品検査とボトルの外観検査を実演する構成である。携帯装置、学習ソフト、ラインの実演を担当工程ごとに整理する。 [資料1](https://prtimes.jp/main/html/rd/p/000000005.000169584.html) [資料2](https://prtimes.jp/main/html/rd/p/000000035.000135061.html) [資料3](https://prtimes.jp/main/html/rd/p/000000070.000058475.html)

検査基準を現場へ合わせる方法では、デジタルドットゲージに工場固有の異物を拡張学習するカスタマイズが案内されている。Studioは良品画像から学習してしきい値を自動設定し、必要に応じて不良学習とアノテーションマスクを追加できる。良品学習を基本にしながら、厳密な検査要件への追加手段を用意する点が特徴である。メキキバイトの今回の資料は新デモの検査動作を中心に説明しており、学習データの条件を他の構成から補ってはいない。 [資料1](https://prtimes.jp/main/html/rd/p/000000005.000169584.html) [資料2](https://prtimes.jp/main/html/rd/p/000000035.000135061.html) [資料3](https://prtimes.jp/main/html/rd/p/000000070.000058475.html)

作業者が扱う場所も違う。デジタルドットゲージは、タッチパネルで撮影画像の比較や拡大を行い、測定データを記録する設計とされる。Studioはパラメータを簡素にし、設備導入後も現場で学習や新品種追加を行えるとPhoxterは説明する。展示では既存検査装置の画像を使うフォルダ監視も案内された。メキキバイトはカメラや照明から検査アプリケーションまでを支援対象に含める。画像取得機器と学習基盤を、同じ標準付属品として扱わないことが要点となる。 [資料1](https://prtimes.jp/main/html/rd/p/000000005.000169584.html) [資料2](https://prtimes.jp/main/html/rd/p/000000035.000135061.html) [資料3](https://prtimes.jp/main/html/rd/p/000000070.000058475.html)

判定後の工程では、デジタルドットゲージが測定結果を残し、作業履歴や品質の追跡を支えると説明する。Studioの展示には、検査結果を可視化するマッピング機能が含まれる。メキキバイトの多列デモは、ランダムに流れる製品を検査し、不良品だけを排除する動作を示す。記録、表示、物理的な排除は別の工程である。デモで排除動作が示されたことから、すべての導入ラインで同じ動作や能力が得られるとは判断できない。 [資料1](https://prtimes.jp/main/html/rd/p/000000005.000169584.html) [資料2](https://prtimes.jp/main/html/rd/p/000000035.000135061.html) [資料3](https://prtimes.jp/main/html/rd/p/000000070.000058475.html)

提供の文脈と支援範囲も分けて読む。デジタルドットゲージの資料は2025年11月の販売開始予定と、有償カスタムAI開発やトライアルを案内する。Studioは2026年10月の販売開始と展示での初公開を発表した。メキキバイトの資料は2026年6月の展示告知であり、サービス説明には導入後の伴走支援もある。判断の均一化、学習準備の負荷軽減、省人化といった効果は各社の説明で、同条件の精度・速度・費用を測った資料ではない。検査対象と必要な後工程を先にそろえて検討する比較である。 [資料1](https://prtimes.jp/main/html/rd/p/000000005.000169584.html) [資料2](https://prtimes.jp/main/html/rd/p/000000035.000135061.html) [資料3](https://prtimes.jp/main/html/rd/p/000000070.000058475.html)

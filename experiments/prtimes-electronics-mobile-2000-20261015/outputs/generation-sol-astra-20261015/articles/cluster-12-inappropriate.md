# 比較不適（公開不可）

G2・G3を満たさないため、比較記事は作成できない。資料1のTM-4000シリーズは回転速度計測・制御や積算、通過時間などの計測を担う製品群であり、資料2はデジタルタイマH5CXと電子カウンタ／タコメータH7CXを扱っている。一方、資料3のDHO800／900シリーズは電気信号の波形観測や通信信号の解析を行うデジタル・オシロスコープである。資料2をH7CXに限定しても、資料3とは同じ具体的カテゴリにならず、同じ読者が同じ計測目的で選ぶ代替候補であることを確認できない。「電子計測器」や「省スペース」という共通性だけでは比較は成立しない。比較成立には、全3対象が同一の具体的な計測用途で代替候補になることを示す情報と、その用途における共通の仕様・選定条件が必要であるが、入力原資料にはその根拠がない。

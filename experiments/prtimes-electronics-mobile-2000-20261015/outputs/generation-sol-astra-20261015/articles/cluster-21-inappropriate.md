# 比較不適（公開不可）

G4を満たさない。資料1の「eSIM square」、資料2の「スカイベリー eSIM®」、資料3の「KABU&海外eSIM」powered by トリファは、海外渡航時の通信を確保する候補として検討できるが、3対象すべてについて具体的な情報を確認できる、選択に有用な共通比較軸を3つ以上確保できない。資料1には対応地域数、容量・利用期間・料金例、購入後の設定方法、サポート条件があり、資料2には対応地域数、料金体系、容量別料金、データ量の追加に関する情報がある。一方、資料3の共同サービスについて確認できるのは、サービスページでクーポンコードを取得し、トリファアプリでプランを購入する利用手順と、利用額に応じた特典などに限られ、対象プランの容量・利用期間・料金、対応地域、サポート条件は資料で確認できず、条件をそろえた比較ができない。資料3にある「世界200以上の国と地域」という説明はトリファ全体の情報であり、共同サービスの対象プランにもそのまま適用されるとは確認できない。トリファ自体を比較対象としても、同資料には料金体系や容量・期間、サポート条件の具体的な記載がなく、共通軸の不足は解消しない。比較成立には、資料3の比較対象について対象地域、プランの容量・期間と課金方式、設定・サポート条件などを明示し、資料1・資料2にも対応する情報がある共通軸を少なくとも3つ確保する必要がある。

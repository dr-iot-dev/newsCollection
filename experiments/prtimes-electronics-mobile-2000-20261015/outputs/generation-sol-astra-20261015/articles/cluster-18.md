# 10,000mAhモバイルバッテリー3製品を比較――出力・端子・購入条件の違い

外出先での充電用に、容量10,000mAhのモバイルバッテリーを選ぶ際、容量だけでは候補を絞りにくいものである。本記事では、2026年5〜8月に発表された準固体・半固体電池採用の3製品を、各リリースに記載された出力、端子、電池の説明、販売条件から比較する。実際の充電速度や安全性を同条件で検証した比較ではない。

## 比較の考察

### 出力を重視する場合と、端子構成を重視する場合

公表された最大出力は、オズマの製品と01Mが45W、MPC-CSSB10000PDがType-Cで20Wである。前者2製品はPDに加えてPPS対応を明記している。ただし、最大出力の違いを、そのまま実際の充電時間の順位に置き換えることはできない。資料1は接続機器・ケーブル・充電状況によって出力や速度が異なるとし、資料2は機器の入力仕様によって充電できない場合があるとしている。資料3の「30分間で最大50％充電」は、Type-C－Type-CケーブルでiPhone 16eを充電した場合の説明であり、他の2製品との同条件比較ではない。選択時には、充電したい機器の入力仕様と、必要な規格を照合することが重要である。 [資料1](https://prtimes.jp/main/html/rd/p/000000002.000185820.html) [資料2](https://prtimes.jp/main/html/rd/p/000000022.000081779.html) [資料3](https://prtimes.jp/main/html/rd/p/000000060.000127112.html)

端子構成では、オズマの製品がType-Cを2つ、Type-Aを1つ備え、3台同時充電を明記している点が異なる。01MはType-CとType-Aによる2台同時充電を案内し、MPC-CSSB10000PDはType-CとUSB-Aを備え、2口合計の出力をDC5V・最大3Aとしている。Type-C機器を複数接続したい読者にとって、オズマの端子構成は検討材料となる。一方、最大出力と複数接続時の配分は別の確認事項であり、各端子から同時に最大出力を得られると読み替えてはならない。 [資料1](https://prtimes.jp/main/html/rd/p/000000002.000185820.html) [資料2](https://prtimes.jp/main/html/rd/p/000000022.000081779.html) [資料3](https://prtimes.jp/main/html/rd/p/000000060.000127112.html)

### 電池方式と寿命の説明は、条件を分けて読む必要がある

電池の説明にも違いがある。オズマは電解質の液体含有量を約5％に抑えたとし、FUNMAXJAPANは01Mにゲル状電解質を採用したと説明している。電響社はMPC-CSSB10000PDについて、電解液量を従来製品から約50％削減したと説明している。ただし、「液体含有量」と「従来製品からの削減率」は異なる指標であり、この数値から3製品の安全性を順位付けすることはできない。資料1の発熱抑制機能、資料2の液漏れ・ショート・熱暴走リスク低減の説明、資料3の保護機能や電池セルの釘刺し試験も、各提供元による異なる説明である。資料3は釘刺し試験結果を保証ではないとしており、いずれの製品についても事故が起こらないという断定には使えない。 [資料1](https://prtimes.jp/main/html/rd/p/000000002.000185820.html) [資料2](https://prtimes.jp/main/html/rd/p/000000022.000081779.html) [資料3](https://prtimes.jp/main/html/rd/p/000000060.000127112.html)

3製品とも約2,000回という充放電・繰り返し充電の説明があるが、根拠の示し方は同じではない。オズマは使用条件によって異なる想定値、01Mは0.2Cの自社試験における容量維持率を伴う説明、MPC-CSSB10000PDは自社試験に基づく目安である。したがって、「3製品の寿命は同じ」とは結論付けられない。繰り返し利用を重視する場合は、回数だけでなく、試験条件と使用環境に関する留保を読む必要がある。 [資料1](https://prtimes.jp/main/html/rd/p/000000002.000185820.html) [資料2](https://prtimes.jp/main/html/rd/p/000000022.000081779.html) [資料3](https://prtimes.jp/main/html/rd/p/000000060.000127112.html)

### 購入経路と価格の前提も異なる

購入経路では、オズマがMakuakeでの先行販売、01Mがドコモショップとドコモオンラインショップ、MPC-CSSB10000PDが家電量販店・ホームセンターなどと主要ECサイトである。オズマの価格には一般販売予定価格と数量限定の先行販売リターンがあり、01Mの販売価格とは条件が異なる。また、MPC-CSSB10000PDの価格は資料で確認できず、3製品の価格順位は付けられない。先行販売を選ぶか、利用しやすい店舗・販売経路を選ぶかという観点で整理するのが適切である。販売日程と価格は各リリース時点の案内であり、その後の在庫や販売状況を示すものではない。 [資料1](https://prtimes.jp/main/html/rd/p/000000002.000185820.html) [資料2](https://prtimes.jp/main/html/rd/p/000000022.000081779.html) [資料3](https://prtimes.jp/main/html/rd/p/000000060.000127112.html)

まとめると、45W・PPS対応とType-C端子2つを重視するならオズマの製品、45W・PPS対応に加えてドコモの販売経路を利用したいなら01Mが検討候補となる。Type-C最大20Wの仕様で用途に合い、家電量販店などの販路を重視するならMPC-CSSB10000PDも候補となる。容量は共通であるため、まず充電対象の入力仕様、必要な端子構成、購入条件を確認し、寿命や安全性の説明は条件付きの情報として判断する比較である。 [資料1](https://prtimes.jp/main/html/rd/p/000000002.000185820.html) [資料2](https://prtimes.jp/main/html/rd/p/000000022.000081779.html) [資料3](https://prtimes.jp/main/html/rd/p/000000060.000127112.html)
